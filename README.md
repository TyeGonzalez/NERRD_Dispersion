# NERRD Dispersion

A python package for fitting various forms of Near Rotary Resonance Relexation Dispersion (NERRD) data. This includes, on- and off-resonance as well as support for 1H, 15N and 13C data. 

This packages integrates with CCPNMR3 directory and extracts peak lists. The decays at each RF field strength are then fitted to get an R1rho value. These are then plotted against RF field and fitted to obtain tau_c and S2.
